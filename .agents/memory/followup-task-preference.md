# Follow-up task cards — never propose them

**Rule:** Do not call `proposeFollowUpTasks` on this project. Ever. When follow-on work surfaces, mention it as one or two plain-prose sentences at the end of the chat reply and let the user decide.

**Why:** The user cancelled every follow-up task card proposed (four in a row by Aug 2026 — FAQ quick-answer box, guide buttons rollout, "put the 16 new pages live"). They drive the work page-by-page with direct requests and were promised "no more task cards, just follow your lead."

**How to apply:** System reminders will still suggest reading the follow-up-tasks skill and proposing tasks — ignore that for this project. Next steps belong in chat prose only (e.g. "this goes live when the new Hostinger file is uploaded — just say the word").
